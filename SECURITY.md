# Security Policy

## Supported versions

Security fixes are provided for the latest released version only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** button on the repository Security tab to send a private report. Include affected versions, reproduction steps, impact, and any suggested mitigation.

If private vulnerability reporting is not enabled, contact the repository owner privately and ask for a secure reporting channel without including sensitive details in the first message.
